# CookieRun VS2026

Visual Studio 2026 / .NET 10 Windows Forms 버전입니다.

## 포함 기능

- 쿠키 선택
- 1라운드 보스 없음
- 2~4라운드 보스
- 패링 5초 쿨타임, 성공 시 즉시 초기화
- 패링한 공격이 보스에게 적중할 때 보스 시간 감소
- 강멜로디언의 음표/리듬 패턴
- enemy1 일반 장애물
- enemy2 지중 팝업 장애물
- Player3 패링 연출
- enemy6 강멜로디언 '돼!' 연출

## 실행

Visual Studio 2026에서 `CookieRunVS2026.csproj`를 열고 실행하세요.

## 에셋

현재 저장소에 있던 Player1/2, enemy1~5를 VS2026 폴더에도 복사합니다.
Player3.png와 enemy6.png는 대화에서 파일 바이트가 제공되지 않아 자동 업로드하지 못했습니다. 두 파일을 `CookieRun/VS2026/Assets`에 추가하면 해당 연출이 활성화됩니다.
